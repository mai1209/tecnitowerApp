Tecnitower
Esquema de Funcionamiento

El usuario usa la app desde cualquier lugar. La nube envía el comando a un agente local dentro del negocio, y ese agente se comunica con el controlador físico a través del Elfin.

Idea Principal

La nube gestiona usuarios y comandos. El equipo local conecta esa nube con el controlador físico.

Nube

App Móvil Visualiza temperaturas, alarmas y setpoint.
↓
Backend Tecnitower Valida usuarios, procesa órdenes y administra equipos.
↓
EMQX MQTT Canal seguro entre la nube y el agente local.

Local del Cliente

Agente Local Mac, Raspberry o mini PC conectada al WiFi/LAN del local.
↓
Elfin EW11A Puente entre red local y RS485.
↓
TC900E Controlador que entrega lecturas y recibe cambios.

Recorrido de la información

App → Backend → EMQX → Agente Local → Elfin → TC900E
TC900E → Elfin → Agente Local → EMQX → Backend → App
En esta solución el Elfin no se conecta directamente a internet. El equipo que publica y recibe por MQTT es el agente local.
